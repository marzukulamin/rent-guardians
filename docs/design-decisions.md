# Rent Guardian design decisions

UI UX Pro Max was downloaded from https://github.com/nextlevelbuilder/ui-ux-pro-max-skill and its search script was run for the new rental marketplace. The first broad match suggested an unrelated marketing pattern; a narrower real-estate query produced the guidance in design-system-match.md. Its recommendations informed the clean property cards, layered 3D preview, responsive layouts, focus states and progressive forms.

The user's actual brand guide takes precedence over generated palettes and fonts: navy #16162A, blue #1D81CD, Poppins, the supplied winged-home monogram, the official slogan “Your Safety Is Our System”, and muted secondary text. The default screen exposes property search and actual results. Operational screens emphasise decisions and tracking.

The two local interior images are illustrative licensed Unsplash samples, not photographs of the sample Bangladesh addresses:

- Riyas Mohammed: https://unsplash.com/photos/a-living-room-with-a-gray-couch-and-a-white-rug-_BBps6MAJ2w
- Lisa Anna: https://unsplash.com/photos/a-living-room-with-a-white-couch-and-large-windows-9ag1NYrdE3I

The Three.js apartment is a procedural concept preview and explicitly labelled as such. Uploaded scanned property tours are an integration step. Reduced-motion preferences disable automatic rotation; orbit, zoom, pause and reset controls remain available.
